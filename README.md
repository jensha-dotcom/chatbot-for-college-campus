# chatbot-for-college-campus
chatbot for college campus


## About
The College Campus Chatbot is a web application that helps students get information about the college. It provides answers to questions related to admissions, courses, departments, placements, fees, and campus facilities.

## Features
- Student-friendly chatbot
- College information
- Admission details
- Course details
- Placement information
- Easy to use interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run
1. Install the required packages.
2. Run `python app.py`.
3. Open `http://127.0.0.1:5000` in your browser.
